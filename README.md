# MySQL Assignment 2: Querying Data

## Overview
This assignment focuses on querying data in MySQL using filtering, sorting, aggregate functions, grouping, and joins.

## Requirements
- MySQL Server 8.0 or above
- MySQL Workbench
- Completed MySQL Assignment 1
- Employee database populated with the provided DML insert statements.

## Database Tables

1. **Employees**
2. **Departments**
3. **Locations**

## SQL Concepts Covered

### 1. Basic Querying
- DISTINCT
- Column Aliases (AS)
- WHERE Clause
- Comparison Operators
- NULL Handling
- UPDATE

### 2. Sorting and Grouping
- ORDER BY
- LIMIT
- GROUP BY
- HAVING

### 3. Aggregate Functions
- SUM()
- MIN()
- MAX()
- AVG()
- COUNT()

### 4. Joins
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

## Execution Steps

1. Open MySQL Workbench.
2. Connect to your MySQL Server.
3. Select the employee database:

```sql
USE employee;
```

4. Ensure the Employees, Departments, and Locations tables contain the required data.
5. Open the Assignment 2 SQL script.
6. Execute the queries and verify the results.
